# Engineering Portfolio — GitHub Pages

A static portfolio for physical AI, robotics simulation, XR, sensor simulation and automotive projects. Plain HTML and CSS, no build step, no JavaScript required.

## Deploy

1. Create a public repository named `YOUR_USERNAME.github.io`.
2. Upload the contents of this folder to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.

## Customize

Search the HTML files for:
- `your-email@example.com`
- `https://github.com/`
- `https://www.linkedin.com/`
- `https://www.fab.com/`

Replace these with your real links.

The design is intentionally text-first — a serif headline face (Source Serif 4) paired with system UI fonts, a warm paper background, and hairline rules instead of imagery, so it reads cleanly with or without project photos. If you add screenshots or renders later, drop them under `assets/` and reference them from the relevant page.
